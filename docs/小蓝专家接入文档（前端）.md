# 小蓝专家接入文档（前端）

## 这是什么

一个可嵌入任意页面的**智能体悬浮抽屉组件**。引入后：

- 页面右下角出现一个**可拖动的圆形悬浮按钮**（小蓝形象图标）
- 点击按钮，从页面右侧滑出**抽屉**，抽屉内是智能体对话页
- 抽屉浮在宿主页面最上方，可以拖动左边框调整宽度，支持**全屏**、**关闭**、**遮盖层**等交互
- 宿主页面可通过方法与智能体页面**收发消息**、接收会话 ID 等数据

## 引入方式

`ckc-expert-agent.umd.js` 在各环境有固定的部署地址，按所在环境选择对应地址引入：

| 环境 | 脚本地址 |
| --- | --- |
| dev | `http://lf18kg-dev.life.cpic.com/center/exts/ckc-expert-agent.umd.js` |
| sit | `http://lf18kg-sit.life.cpic.com/center/exts/ckc-expert-agent.umd.js` |
| prod | `http://lf18kg.life.cpic.com/center/exts/ckc-expert-agent.umd.js` |

```html
<!-- 示例：dev 环境；sit / prod 换成上表中对应环境的地址 -->
<script src="http://lf18kg-dev.life.cpic.com/center/exts/ckc-expert-agent.umd.js"></script>
```

> 脚本地址要和创建时传的 `options.env` 保持同一环境（例如 sit 环境的页面引 sit 的脚本、传 `env: 'sit'`），避免智能体页面加载到别的环境去。

引入后全局只有一个方法：`window.createCkcDrawer`。

> 也支持 UMD 规范的模块引入（`require` / `import`），导出的 `createDrawer` 与 `window.createCkcDrawer` 是同一个方法。

## 快速开始

```html
<script src="http://lf18kg-dev.life.cpic.com/center/exts/ckc-expert-agent.umd.js"></script>
<script>
  // 创建：页面上出现悬浮按钮（此时抽屉尚未初始化）
  var drawer = window.createCkcDrawer({
    env: 'dev',          // 运行环境：dev / sit / pro（与脚本地址同一环境）
    token: 'xxxx',       // 鉴权 token（必填）
    agentCode: 'agent-01' // 智能体编码（必填）
  });

  // 点击悬浮按钮即会打开抽屉；也可以用代码控制：
  drawer.open();
</script>
```

## 创建参数（DrawerOptions）

```js
var drawer = window.createCkcDrawer(options);
```

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `env` | `'dev' \| 'sit' \| 'pro' \| 'local'` | （必填） | 运行环境，决定智能体页面的站点域名 |
| `token` | `string` | （必填） | 鉴权 token，传给智能体页面用于鉴权 |
| `agentCode` | `string` | （必填） | 智能体编码，决定抽屉内使用哪个智能体 |
| `sessionId` | `string` | 不传 | 会话 ID，传入时续接对应会话；**不传时智能体页面会生成一个 sessionId 发回来**（见「接收 sessionId」） |
| `payload` | `{ message: string, files: {name, url, type}[] }` | 不传 | 预置消息/附件，智能体页面就绪后自动传给它 |
| `width` | `number` | `500` | 抽屉初始宽度（px） |
| `minWidth` | `number` | `200` | 拖动调整宽度时的最小宽度（px） |
| `maxWidth` | `number` | 视口宽度 | 最大宽度（px）；智能体页面点「全屏」时抽屉宽度变为该值 |
| `mask` | `boolean` | `false` | 是否在抽屉打开时给左侧页面区域加**遮盖层**（半透明遮罩，宿主页面变暗且不可操作）；开启后点击遮盖层会关闭抽屉 |

## 控制对象（DrawerHandle）

`createCkcDrawer` 的返回值是控制抽屉的唯一入口，所有操作都通过它的方法完成。

| 成员 | 说明 |
| --- | --- |
| `drawer.isOpen` | 当前抽屉是否处于打开状态（`true` / `false`） |
| `drawer.open()` | 打开抽屉（首次调用时才初始化） |
| `drawer.close()` | 关闭抽屉。**只是隐藏，不销毁**：智能体页面继续运行，滚动位置、表单等状态保留，仍会继续产出数据 |
| `drawer.setWidth(px)` | 设置抽屉宽度（自动限制在 min / max 之间） |
| `drawer.sendMessage(payload)` | 向智能体页面发送一条业务消息（格式 `{message, files}`） |
| `drawer.receiveMessage(handler)` | 接收智能体页面发来的**消息**（`{message, files, ...}`），返回取消监听的函数 |
| `drawer.receiveSessionId(handler)` | 接收智能体页面生成的 sessionId，返回取消监听的函数 |
| `drawer.onVisibilityChange(handler)` | 监听抽屉显示/隐藏变化，返回取消监听的函数 |
| `drawer.destroy()` | 彻底销毁：移除悬浮按钮、抽屉和遮盖层，解绑所有事件 |

### 显隐控制

```js
drawer.open();   // 打开
drawer.close();  // 关闭（只是隐藏，智能体页面继续运行）
drawer.isOpen;   // 查询当前状态
```

用户点击悬浮按钮、智能体页面内的关闭按钮，效果与 `open()` / `close()` 相同。

### 发送消息

```js
drawer.sendMessage({
  message: '你好，帮我分析这份报告',
  files: [
    { name: 'report.pdf', url: 'https://example.com/report.pdf', type: 'application/pdf' }
  ]
});
```

- 智能体页面尚未就绪时调用会**自动排队**，就绪后按顺序补发，不用担心调用时机
- 发送失败（如智能体页面停留在错误页）也会排队，恢复后自动补发

### 接收消息

智能体页面分析完成后会把结果消息发过来，用 `receiveMessage` 接收：

```js
var off = drawer.receiveMessage(function (message) {
  // message: { message: '分析完成', files: [{ name: '分析报告.pdf', url: 'https://...', type: 'pdf' }], ...其它附带字段 }
  console.log('收到消息', message);
});

off(); // 不再需要时调用返回的函数取消监听
```

- `message.message` 是消息文本，`message.files` 是附件/产物文件列表（`{name, url, type}`）
- 除这两个字段外，智能体页面还可以附带其它自定义字段，原样透传到回调参数上

### 接收 sessionId

创建时**没有传** `sessionId` 的话，智能体页面会自己生成一个并发送出来。宿主可以把它持久化，下次创建时传入即可续接同一会话：

```js
drawer.receiveSessionId(function (sessionId) {
  localStorage.setItem('agent-session-id', sessionId);
});

// 下次创建时续接会话：
var drawer = window.createCkcDrawer({
  env: 'dev',
  token: 'xxxx',
  agentCode: 'agent-01',
  sessionId: localStorage.getItem('agent-session-id') // 传入上次保存的 sessionId
});
```

### 监听显隐变化

```js
drawer.onVisibilityChange(function (visible) {
  console.log(visible ? '抽屉已打开' : '抽屉已关闭');
});
```

用户点智能体页面内的关闭按钮、点遮盖层触发的关闭，同样会通知到这里。

### 彻底销毁

```js
drawer.destroy();
```

调用后悬浮按钮、抽屉、遮盖层全部从页面移除，事件解绑，该 `drawer` 实例不再可用。

## 页面交互说明

| 交互 | 行为 |
| --- | --- |
| 拖动悬浮按钮 | 移动按钮位置（不会打开抽屉） |
| 点击悬浮按钮 | 打开抽屉（首次点击时初始化） |
| 拖动抽屉左边框 | 调整抽屉宽度（左拖变宽、右拖变窄，限制在 min / max 之间） |
| 智能体页面加载完成前 | 抽屉内显示**加载动画**（转圈 +「加载中…」），加载完成后自动消失；若 10 秒仍未加载完成会自动停止动画并在浏览器控制台提示 |
| 智能体页面上的「全屏」按钮 | 抽屉宽度变为最大值，按钮变为「取消全屏」；再点恢复默认宽度 |
| 智能体页面上的「关闭」按钮 | 关闭抽屉（只是隐藏，智能体页面继续运行） |
| 点击遮盖层（`mask: true` 时） | 关闭抽屉 |

抽屉关闭后再次打开，智能体页面不会重新加载——里面的滚动位置、输入内容、运行状态都还在。
